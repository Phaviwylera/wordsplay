Offline Ethereum address converter

Verify address/private-key pairs on this device and create a CSV containing public addresses only. The CSV can then be scanned with Walleto’s existing public-address upload.

This page will not read a key file while opened from a website. Use the dashboard’s download link to save this single HTML file, then open the downloaded file directly in your browser (its address should begin with file://). Disconnect from the internet and close Tailscale before processing keys.
Private keys are secrets. This tool processes them locally and contains no network requests, uploads, analytics, external scripts, or browser storage. For strongest isolation, disconnect Wi-Fi/Ethernet and close Tailscale before using it. Browser memory is not guaranteed secure erasure. Never process keys protecting valuable funds with an unaudited tool.

Supported rows contain an Ethereum address followed by its private key, separated by a tab, comma, semicolon, pipe, or spaces. Header rows are optional. A pair is exported only if the key derives exactly the address on that row.

Disconnect from the internet and close Tailscale before selecting the key file.
